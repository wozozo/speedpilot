# Privacy Policy for SpeedPilot

Last updated: June 16, 2026

SpeedPilot is a Chrome extension for controlling HTML5 video playback speed and seeking with keyboard shortcuts.

## Data Collection

SpeedPilot does not collect, sell, transmit, or share personal information, browsing history, video watch history, page content, analytics data, or advertising identifiers.

## Stored Data

SpeedPilot stores only extension settings, including:

- Keyboard shortcuts
- Speed increment and skip duration
- Overlay visibility and opacity
- Whether to reuse the last selected speed
- Site-disable patterns entered by the user

These settings are stored with Chrome Storage Sync. If Chrome sync is enabled in the user's browser, Chrome may sync these settings through the user's Google account according to Chrome's own sync behavior. SpeedPilot does not operate any server and does not receive this data.

When "Force Last Saved Speed" is enabled, the last selected speed is stored locally in the browser for the current site using local storage.

## Permissions

SpeedPilot uses the `storage` permission to save user settings.

SpeedPilot runs a content script on web pages so it can find HTML5 video elements, update playback speed, seek within the video, and display the optional speed overlay. The extension does not read page text, forms, passwords, cookies, or unrelated page data.

## Third Parties

SpeedPilot does not use third-party analytics, advertising, tracking, remote code, or external APIs.

## Limited Use

The use of information received from Chrome extension APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## Changes

This policy may be updated when SpeedPilot changes how it handles data. Updates will be reflected by the date at the top of this document.
